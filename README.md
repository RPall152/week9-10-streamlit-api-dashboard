# 🚀 Week 9 – Streamlit Intelligence Platform

## 📌 Project Description
A multi-page **Streamlit web application** that converts a Python-based system into a fully interactive platform using **SQLite**, **RBAC**, **analytics**, and **AI-assisted insights**.  
The project demonstrates professional web app architecture, secure authentication, CRUD operations, data visualization, and AI integration.

---

## ✨ Features
- 🔐 **Secure Authentication** with role-based access (user, analyst, admin)
- 🗂️ **Three Managed Domains**
  - Cyber Incidents
  - Datasets Metadata
  - IT Tickets
- 📝 **Full CRUD Operations** for each domain
- 📊 **Interactive Analytics & Visualizations** (Plotly)
- 🤖 **AI-Powered Assistance**
  - Domain-specific AI chat
  - One-click AI summaries for analytics
- 🧠 **Session State Management** using Streamlit
- 🧱 **Clean MVC-style Project Structure**

---

## 🛠️ Technical Implementation
- **Frontend:** Streamlit (multi-page app)
- **Backend:** Python + SQLite
- **Database Layer:** Parameterized SQL queries (SQL injection safe)
- **Data Handling:** Pandas
- **Visualization:** Plotly
- **AI Integration:** OpenAI API 
- **Architecture:** Modular (`data`, `services`, `pages`, `utils`)
- **Security:** Role-based permissions + session state
